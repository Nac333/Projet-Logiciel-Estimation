# Image to Code — adaptation AITE

Source: https://github.com/Leonxlnx/imagegen-skills/tree/main/skills/image-to-code (MIT). Adaptation AITE; pack complet non installé.

Partir de la maquette explicitement choisie par l'utilisateur. Si aucune sélection n'existe, produire les propositions dans un espace isolé puis attendre son choix. Extraire couleurs, typographie, espacements, bordures et états; ne pas inventer les détails illisibles. Implémenter uniquement le périmètre visuel autorisé dans la technologie existante. Conserver géométrie, calibration, PDF, données, calculs, raccourcis et export. Comparer les captures avant/après à tailles identiques; tester interactions et focus. Une image générée ne prouve pas le fonctionnement d'un outil de relevé.

Lire aussi `$aite-validation-visuelle` et `DESIGN.md` avant toute modification.
